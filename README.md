# APEX CELL: battery pack design for Windows

Battery pack design software for EV, e-bike and Formula Student packs, by [APEX LABS](https://apexlabspro.com).
Lay out the pack, route the busbars, run your duty cycle and see the temperature of every cell.
This repository holds the official installers and release notes only. There is no source code here.

- **Website:** https://apexlabspro.com/apex-cell
- **Download the latest version:** [Releases](../../releases/latest) or https://apexlabspro.com/downloads
- **Free battery pack calculator:** https://apexlabspro.com/battery-pack-calculator
- **How results are checked:** https://apexlabspro.com/validation
- **Prices:** from $19.99 a month, with a free 15-day trial you start inside the app: https://apexlabspro.com/licence

## Check your download

Each release lists the installer's SHA-256. In PowerShell:

```powershell
Get-FileHash .\APEX-CELL-Setup-<version>.exe -Algorithm SHA256
```

The installer is not yet code-signed, so Windows SmartScreen may say the publisher is unknown. Choose **More info**, then **Run anyway**.
